# Repo-to-Promo

> **This repo is a stub. The working project lives at
> [hermes-max100/Repo2Video](https://github.com/hermes-max100/Repo2Video).**

Repo-to-Promo was created 2026-09-04 as the original "repository turns into
a short promo demo" idea, but it never got past an AI Studio banner README.

Repo2Video (same morning, same org) is where the idea actually lives:

- `pipeline/` — a working, free/local pipeline: GitHub URL in, 30–60s
  vertical IG clip out (Python + ffmpeg, no paid APIs). Verified end-to-end
  on `hermes-max100/TradingAgents` (35s, 1080×1920).
- `app/` — the original Android app skeleton (Gemini script + Veo video +
  ElevenLabs voiceover; needs paid keys, no local encoder).

Go to Repo2Video for the code, the README, and the roadmap.
